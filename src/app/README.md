# src/app

Owner: platform and online play agent (for now). The art and sound agent replaces the placeholder shell with the real UI in `src/ui`.

## Layers

- `controller.ts`: `AppController`, the only object a UI needs. It owns the current room session and exposes:
  - **State:** `getState()` and `subscribe(listener)` return an `AppState` with `screen` (`home` or `room`), the remembered `name`, `linkCode` (from a share link), `link` (the room's share link), `homeError`, and `session` (a `SessionSnapshot` from `src/net`, or null).
  - **Room actions:** `hostRoom(name, { online, seats? })` (online `false` plays solo, fully offline), `joinRoom(codeOrLink, name)`, `leaveRoom()`, `goHome()`.
  - **Lobby actions (host):** `addBot(n)`, `fillWithBots(total)`, `removeSeat(id)` (bots are removed, humans are kicked and banned from the room), `updateSettings({ pace, roles })`, `start()` (returns an error message or null), `backToLobby()` (after a game ends: everyone returns to the same room's lobby with bots and settings kept, friends who left lose their seats, and the next `start()` deals a new game; `lobby.round` counts games started). Anyone: `rename(name)`.
  - **Game intents:** `chat(channel, text)`, `whisper(to, text)`, `vote(target | null)`, `judge(ballot)`, `nightAction(targets | null)`, `reveal()`, `setWill(text)`, `setDeathNote(text)`, `ready(bool)`, or `send(intent)` for any engine `Intent`. Each returns an id; a rejected intent shows up as `session.lastRejection` with the same id.
  - **Claude bot chat (host only):** `setClaudeKey(key, { remember })` (direct mode: the key stays in this browser, in memory plus localStorage only with `remember`, and goes only to Anthropic), `setClaudeRelay(url, passphrase, { remember })` (relay mode: the host's own relay from `relay/` holds the key; this browser sends only the passphrase, and only to the relay), `setClaudeMode('key' | 'relay')`, `setClaudeSettings({ model, workspaceId, enabled })`, `testClaude()` (one tiny request; resolves with the status), `forgetClaude()` (key and relay), and `botTranscript()` (this game's bot lines, each tagged `source: 'claude' | 'scripted'` with a fallback `reason`). `state.claude` has `status` (`off`, `ok`, `invalid-key`, `browser-blocked`, `relay-error`, `rate-limited`, `degraded`, with a ready-to-show `detail`), `mode`, `hasKey`, `hasRelay`, `relayUrl`, `ready`, `remembered`, `enabled`, `model`, `workspaceId`, call and line counts, and estimated cost. It never contains the key or the passphrase.
  - **Host reload resume:** `saveHost()` (keep a copy of the hosted room in `hostStore`), `suspendHost()` (save, then go quiet without ending the game; for `pagehide`), and `resumeHost()` (bring back the saved room after a reload; returns false if there is no save, the save is from another build (`buildId`), or it is older than 10 minutes). `leaveRoom()` deletes the save.
  - `controller.host` is the `HostSession` when this browser hosts, else null.
- `shell.ts`: a plain DOM renderer over the controller. It is a placeholder: swap `mountShell` for the real UI and keep the controller.
- `format.ts`: plain-text helpers (phase labels, event descriptions, role names).
- `sw.ts` and `assetCache.ts`: a service worker, built to `<base>sw.js`, that serves Vite's hashed build files (`<base>assets/*`: code, images, sounds) cache-first. Their names change with their content, so a cached copy never goes stale; GitHub Pages only lets browsers cache them for ten minutes, so without it a reload (including the host's resume) or a later visit revalidates every file. It never handles pages, other origins, non-GET, or Range requests, and keeps at most 600 files (the oldest go first). `main.ts` registers it in production builds.
- `main.ts`: boot. Builds the controller, mounts the UI, handles `?room=` links (a remembered name rejoins automatically), and keeps the hosted room resumable. It saves the room to `sessionStorage` every 5 s and when the tab is hidden. On `pagehide` it suspends the room without ending it. On boot it resumes a saved room before anything else. The Leave button still ends the room for everyone.

## Reading a session snapshot

`state.session` (`SessionSnapshot` in `src/net/session.ts`):

- `status`: `connecting`, `reconnecting`, `lobby`, `playing`, `ended`, `closed` (host left, kicked, or replaced; see `notice`), or `error` (could not join; see `notice`).
- `lobby`: seats, settings, the role list in use, and its validation.
- `view`: the engine `PlayerView` for this player. `view.events` holds every event this player has received this game, in order.
- `clockOffset`: add to `Date.now()` to get host time; phase timers (`view.phase.endsAt`) are in host time.
- `network` (host): whether friends can reach the room (`offline`, `opening`, `open`, `error`).
- `notice`: `{ code, message }` with a ready-to-show message for `closed` and `error`.

## Test hooks

E2E tests drive the UI through these. Keep them when restyling (or update `tests/e2e` in the same change).

- `window.__vesper`: the `AppController`. With `localStorage['vesper.netlog'] = '1'`, `window.__vesper.netLog` records every message received from the host.
- `?net=peerjs` or `?net=trystero-nostr` forces one transport (default: PeerJS with Trystero fallback).
- `?claudeCalls=N` lowers the per-game Claude call budget (cost control for tests).
- `?sw=0` unregisters the service worker and deletes its cache (debugging). A page the worker controls keeps using it until the page goes away, so the page first tells the worker to stop caching (`'off'`), unregisters it, reloads once to drop it, then deletes the cache.
- The game UI (`src/ui`) is the default: `src/ui/index.ts` exports `mountUi(root, controller)` returning a dispose function, the same shape as `mountShell`. It loads as its own chunk; if it fails to load, the page logs it and shows the shell. `?ui=shell` mounts the plain shell, the fallback for browsers where the stage doesn't work (`?ui=v2` is accepted and means the default). `<html data-ui>` says which UI is mounted (`v2` or `shell`). Share links carry the host page's `ui`, so a host on the shell invites friends to the shell.
