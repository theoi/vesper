# src/engine

Owner: rules engine and bots agent.

Pure, deterministic, JSON-serializable rules engine with seeded randomness. No DOM, no networking, no clock: callers pass `now` in milliseconds.

Import everything from `src/engine/index.ts`. Types live in `types.ts`.

| Function                                    | Returns                     | Notes                                                                      |
| ------------------------------------------- | --------------------------- | -------------------------------------------------------------------------- |
| `createGame(config, seed, now)`             | `{ state, events }`         | Deals roles from the seed; starts in `reveal`.                             |
| `applyIntent(state, playerId, intent, now)` | `{ state, events, error? }` | Rejected intents return `error` and leave the state unchanged.             |
| `tick(state, now)`                          | `{ state, events }`         | Advances phases whose timer ran out. Schedule with `nextDeadline(state)`.  |
| `viewFor(state, playerId, { sinceSeq? })`   | `PlayerView`                | Exactly what that player may know. `sinceSeq` limits `events` to new ones. |
| `eventsFor(events, playerId)`               | `GameEvent[]`               | Filters events by `audience`; use it to forward a step's events to a peer. |
| `validateRoleList(roles, playerCount)`      | `{ ok, errors, warnings }`  | For the host's custom role list.                                           |
| `presetFor(playerCount)` / `PRESETS`        | `Preset`                    | Built-in setups for 7–15 players (with fallbacks from 4 to 16).            |
| `defaultConfig(players, overrides?)`        | `GameConfig`                | Preset roles plus default timers and options.                              |

`GameState` is host-only and must never be sent to clients. Every event carries an `audience` (`'all'` or a list of player ids).

## Staging cues

The UI picks night, dawn, and death sequences from engine events. Build every sequence from one player's `PlayerView` (its `events`, `players`, `trial`, `graveyard`, and `you`), never from `GameState`, even when this browser hosts the game. Everything below is already safe for that player. `src/engine/staging.test.ts` pins each row, so a change to an audience or field fails there first. `EventBase.seq` is the same for everyone in a room, which makes it a good seed for picking a variant.

| Cue                   | Source                                                                                                                                                                                                                                                                                                                                                                           | Who receives it                                    |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Role deal             | `roleAssigned`: `role`, `teammates` (Syndicate only), `accuserTarget` (Accuser only). | Saves                 | `attackedSurvived` with `savedBy` `healed` or `guarded` (another player's hand) or `vest` or `defense` (their own). `patientAttacked` goes to the Mender, `guardFought` to the Sentinel, `targetSurvived` to the attacker.                                                                                                                                                       | Each result goes to its owner only.                |

Kept secret on purpose until the game ends, so no sequence should try to show it earlier: who visited whom (apart from a Lamplighter's own result), any public sign that a save happened, who attacked a survivor, other players' night choices outside the Syndicate, and, for living players other than the Mourner, whether a Mourner is alive.

## Night history

The host records every night as it resolves (`GameState.nights`) and reveals the whole record to everyone in `gameOver.nights`, for a "what really happened" epilogue in the curtain call. Each `NightRecord` has the `night` number, the `deaths` that night (the same list as that dawn's `dawn` event), and `actions`: one `NightAction` per ability used, in seat order. Players who stayed home are left out.

A `NightAction` names the `actor`, their `role` that night (roles can change later), the ability `kind`, the `target` where it landed, and its `outcome`. `chose` is set when the ability landed somewhere other than the actor's own pick: a Hatchet carrying out the Patron's order, or a distracted Cutthroat turning on its distractor. `visitors` is set for a Lamplighter's watch.

| Ability                   | Outcomes                                                                                                                                                                   |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Any                       | `blocked`: a Muse or Lure distracted the actor, so nothing happened.                                                                                                       |
| `kill`, `stab`, `shoot`   | `killed`; `survived` (role defense, Drifter armor, or a heal held); `intercepted` (a Sentinel took the blow). A Patron whose order the Hatchet carried out gets `ordered`. |
| `investigate`             | `suspicious` or `clear`, as the Augur read it (a frame shows as `suspicious`).                                                                                             |
| `watch`                   | `watched`, with `visitors`.                                                                                                                                                |
| `heal`                    | `saved` (the patient was attacked and lived) or `quiet`.                                                                                                                   |
| `guard`                   | `fought` (an attacker came to the door) or `quiet`.                                                                                                                        |
| `block`                   | `distracted` (the target lost their action) or `resisted` (another distractor, Drifter armor, or a Cutthroat, who attacks its distractor instead).                         |
| `frame`, `embalm`, `vest` | `framed`; `embalmed` (the target died that night) or `quiet`; `armored`.                                                                                                   |
